# Seguridad / Security

**Español** · [English](#english)

HR-Core guarda datos personales de plantillas (fichajes con ubicación, documentos, nóminas). Nos tomamos en serio
cualquier fallo de seguridad.

## Cómo avisar de un fallo

**No abras una incidencia pública.** Usa el aviso privado de GitHub: pestaña *Security* → *Report a vulnerability*
del repositorio. Incluye, si puedes, la versión, los pasos para reproducirlo y su impacto.

- Respondemos en un máximo de 5 días laborables.
- Te tendremos al tanto del arreglo y, si quieres, te citaremos en las notas de la versión.
- Pedimos que no publiques el fallo hasta que haya una versión corregida (máximo 90 días).

## Versiones con soporte

Solo la última versión publicada recibe arreglos de seguridad. Actualiza con `./instalar/actualizar.sh`.

## English

HR-Core stores personal data about staff (time records with location, documents, payslips). We take security
issues seriously.

### Reporting a vulnerability

**Do not open a public issue.** Use GitHub private reporting: the repository's *Security* tab → *Report a
vulnerability*. Please include the version, steps to reproduce and the impact if you can.

- We reply within 5 working days.
- We will keep you posted on the fix and, if you wish, credit you in the release notes.
- Please do not disclose the issue until a fixed version is released (90 days at most).

### Supported versions

Only the latest release receives security fixes. Update with `./instalar/actualizar.sh`.
