# Código de conducta / Code of conduct

**Español** · [English](#english)

Queremos que participar en HR-Core sea una experiencia respetuosa para cualquier persona, sin importar su edad,
cuerpo, discapacidad, etnia, identidad o expresión de género, experiencia, nacionalidad, apariencia, religión u
orientación sexual.

- Trata a los demás con respeto y paciencia; critica ideas, no a personas.
- No se tolera el acoso, los insultos, los comentarios discriminatorios ni publicar datos privados de nadie.
- Quien mantiene el proyecto puede retirar comentarios, código o incidencias que incumplan estas normas, y
  bloquear temporal o definitivamente a quien las incumpla.

Para avisar de un comportamiento inadecuado, escribe a las personas que mantienen el proyecto desde su perfil de
GitHub o usa el aviso privado del repositorio. Se tratará con confidencialidad.

Basado en el [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

---

## English

We want taking part in HR-Core to be a respectful experience for everyone, regardless of age, body size,
disability, ethnicity, gender identity or expression, experience, nationality, appearance, religion or sexual
orientation.

- Treat others with respect and patience; criticise ideas, not people.
- Harassment, insults, discriminatory comments and publishing anyone's private data are not tolerated.
- Maintainers may remove comments, code or issues that break these rules, and temporarily or permanently ban
  those who break them.

To report unacceptable behaviour, contact the maintainers through their GitHub profile or use the repository's
private reporting. Reports are handled confidentially.

Based on the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
